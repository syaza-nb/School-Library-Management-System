# 📚 School Library Management System

The School Library Management System is a web-based application developed to streamline library operations in educational institutions. Built using PHP, MySQL, HTML, CSS, and JavaScript, it enables efficient management of books, borrowing transactions, and user accounts for students, teachers, and librarians.

## ✨ Features

### 👨‍🎓 Student
- Register and log in to the system
- Browse and search the library catalog
- View book availability
- Borrow and return books
- View borrowing history

### 👩‍🏫 Teacher
- Browse and search available books
- Borrow and return books
- View borrowing records
- Monitor due dates

### 👨‍💼 Librarian
- Manage student and teacher accounts
- Add, edit, and remove books
- Manage book categories
- Process book borrowing and returns
- Track overdue books
- Generate library reports

## 🎯 Project Objective

The School Library Management System was developed to digitize and improve library operations by providing an efficient platform for managing books, users, borrowing activities, and returns. The system reduces manual record-keeping and enhances accessibility for students, teachers, and librarians.
